# Phase 0 checklist: definition, governance, desktop prototype

From plan section 20. Phase 0 must complete before Phase 1 code. Do not create production accounts or ingest real data during Phase 0.

## Decisions to resolve (see decisions/decision-log.md)

- [ ] D-01 to D-08 resolved with a recorded owner (hard gate for any code).
- [ ] D-09 to D-14 and D-23 resolved before pilot.

## Work

- [ ] Approve project location and repository ownership.
- [ ] Confirm role counts, scopes, appointment rules, and segregation of duties.
- [ ] Confirm jurisdiction, provenance, DNC handling, contact windows, and retention ownership.
- [ ] Inventory work laptops, browsers, screen sizes, scaling, and network.
- [ ] Select the production host OS.
- [ ] Decide LAN certificate trust and Tailscale topology.
- [ ] Create a data inventory and data-flow diagram.
- [ ] Run a threat-model workshop.
- [ ] Define connected, conversion, sale, callback, no-answer, and DNC as distinct concepts.
- [ ] Decide campaign concurrency, allocation, transfer cutoff, and callback ownership.
- [ ] Define target metrics, periods, calendars, proration, rounding, ramp, and attribution.
- [ ] Define exemption request, approval, escalation, privacy, mass-adjustment, appeal, and reopen rules.
- [ ] Define joiner, mover, leaver, rehire, acting, delegation, and bulk-upload workflows.
- [ ] Approve immutable workforce identity and template ownership.
- [ ] Prototype Agent, Team Captain, Team Leader, and Manager desktop workflows.
- [ ] Test the prototype with two agents and one of each management role.
- [ ] Create ADRs for resolved decisions.
- [ ] Approve release gates and pilot size.
- [ ] Re-estimate the remaining phases.

## Success criteria

- [ ] D-01 to D-08 resolved and recorded.
- [ ] Prototype usable at 1366 x 768 and 150 percent scaling.
- [ ] Agent flow has no hidden controls or accidental shortcuts.
- [ ] Legal and privacy accept the DNC and provenance approach.
- [ ] Threat model has named owners for high-risk mitigations.
- [ ] Role, campaign, target, exemption, and bulk-import decision tables approved.

## Deliverables

Decision log, role and authorization matrix, hierarchy and lifecycle rules, campaign and transfer rules, target and exemption rules, bulk templates, data inventory, threat model, DNC and retention decisions, wireframes and keyboard map, network and host ADRs, test and release-gate baseline, and an updated estimate.
